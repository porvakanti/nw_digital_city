The ground
A district is an L2 area, inside its own coloured kerb. A plot is an L3 group, the paler slab inside it. A lot is one L4 category, one square of land. Land is worth what is spent on it: lots are larger where the money is, so a plot grows both with how many categories it holds and with how much sits on them. Lots stay the same size inside a plot, so an empty one is still an empty one. Traffic follows the same money, so the busiest streets are in the districts that spend most.
